# Implementación

- Renombra el recurso "webcontent/pages/index.html" a "webcontent/pages/landing.html".
- Crea los siguientes recursos:
  - webcontent/pages/index.html
  - webcontent/styles/styles.css
  - webcontent/js/index.js
- Desde index.html se debe hacer referencia a styles.css y a index.js.
- Todo lo referente a estilos, CSS3, etcétera, debe estar en styles.css.
- Todo lo referente a scripting Javascript, debe estar en index.js.
- Descarga la última versión de Phaser 3 desde la página web oficial y ubícalo en "webcontent/js".
- Desde index.html se debe hacer referencia al fichero JS de phaser descargado anteriormente.
- Diseña una página profesional y moderna para el proyecto. Sigue las últimas tendencias en cuanto a diseño. La página debe ser accesible, responsive, adaptable y todo lo que necesite para estar a la última.
- La página muestra un canvas que tiene 800 x 600 píxeles. El canvas está centrado en anchura.
- Los fondos de la página y del canvas son de color negro.
